LTA OJT TRACKER - VERSION 10 LEAVE AND BLANK-FORM UPDATE

Replace index.html, app.bundle.js, and sw.js in the repository root. Keep all other existing repository files.

Day off / leave: select a date and Holiday, PTO, or Bereavement, then save. The reason prints on the corresponding daily row and adds no OJT hours. Delete a label in Recent entries to change it. Full-day leave labels cannot coexist with training hours on the same date.

Blank forms for coworkers: select a week using Previous/Next, then tap Generate Blank Dated OJT Form. Only Monday-Sunday dates and the week-ending date are added to the original template. Employee name, hours, leave labels, totals, and signatures stay empty.

GitHub Pages will update in a few minutes. Open the installed app while online once so it downloads the update. If the old version remains, close it, revisit the GitHub Pages URL in Safari, refresh, then reopen the home-screen app.

Generate OJT Form PDF uses the selected week. The form fills the employee name, week-ending date, daily/category cells, category totals, and weekly total. Signature and approval lines remain blank.

On iPhone, the app first tries to open the native Share sheet. If iOS does not allow that, tap the visible "PDF ready - open it" button, then use the PDF viewer's Share button to Save to Files or Print.

Records stay on each person's device. Use Export Backup regularly; restoring a backup replaces the device's current records.
